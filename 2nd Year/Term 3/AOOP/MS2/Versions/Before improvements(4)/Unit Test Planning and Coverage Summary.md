| Project Name        | GEAR.HR                                                                                                                                                                                                                                                                                             |
| Project Description | GEAR.HR is a Java Swing HR and payroll management system for employees, attendance, leave requests, user roles, and payroll processing. The application uses service classes and repository interfaces so the same business logic can work with JDBC/MySQL repositories or legacy CSV repositories. |


This worksheet documents the unit testing planned for the expanded MotorPH Payroll System. The goal is to identify which core logic is covered, what behavior is verified, and how unit tests protect shared business rules.

Out of scope for this document:

- GUI behavior
- Full login workflows
- Navigation or screen transitions
- Manual database installation/setup outside the application

| Known limitations or untested areas | GUI rendering, file chooser behavior, Swing button actions, full authentication flow, and manual MySQL installation/setup are not covered by these unit tests.
